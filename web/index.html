Production Deployment Recommendations

          

            

              1. Loopback Binding: By default, CoreIP Server Inspector binds exclusively to 127.0.0.1 to prevent accidental network exposure.
            

            

              2. Remote Workstation Access: To permit authorized IT support workstations, deploy behind an internal HTTPS reverse proxy (e.g. Nginx, Caddy) or VPN, and enable server.allow_remote: true in /etc/coreip-inspector/config.yaml.
            

            

              3. Unprivileged Execution: Run the service under the dedicated coreip service user without root privileges.
